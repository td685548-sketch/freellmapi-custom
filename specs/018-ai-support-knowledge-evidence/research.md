**Date**: 2026-11-13. Repository inspection and design decisions; no implementation executed.

1. **Baseline**: PR #16 is MERGED and its lint/build/server four shards/client/CLI checks succeeded. Current local branch already includes subsequent main synchronization. Do not merge/rewrite shared checkout during agent implementation; reviewer handles final synchronization safely.
2. **Current knowledge**: support-knowledge.ts exposes list/upsert/delete/search; docs are settings-backed, search filters role/enabled/category then uses title/tag/paragraph term overlap. The400-character result snippet and runtime knowledgeDocIds do not constitute answer citation verification or revision publication.
3. **Existing runtime**: support-runtime.ts and support-runtime-store.ts own claims, quota reservation, leases, masked persistence/cache and generation deadlines. Extend these instead of a second unguarded execution path. Preserve actual usage and no-provider failure behavior.
4. **Optional product mode**: mode off retains017. Required mode is deliberately knowledge-only: no CRM or business tool output needs to be incorrectly attributed to a KB citation. Tool/CRM evidence is future scope. Non-AI abstention has a distinct replySource and no fake modelUsed.
5. **Formats / packages**: choose txt/md/FAQ JSON using installed runtime facilities. Arbitrary HTML/PDF conversion would need parser/dependency/sandbox design and is not included. An export URL must produce an allowed text content type and satisfy existing DNS-bound safe HTTP.
6. **Persistence**: source bodies/chunks and evaluation questions are potentially sensitive. Encrypt imported text, chunk text, suite cases and detailed reports; keep only necessary IDs/counters/ACL metadata readable. Reuse existing crypto/Db abstractions; no service-local key or secret fallback.
7. **Registry lesson**: migrations are statically registered in server/src/db/migrate/defaults.ts. Agent1 owns both new migration and registration plus the explicit roundtrip list. Lazy bootstrap alone is not acceptance.
8. **Retrieval**: bounded Unicode/accent-normalized lexical retrieval works without assuming FTS5/embedding capabilities on every adapter. Its ranking is intentionally named lexical coverage/score, not probability/confidence. Role filtering precedes new-source decryption/ranking; legacy role filtering precedes chunking/ranking.
9. **Revision freshness**: immutable published revision references plus a recomputed active snapshot cover new-source ACL/publication and legacy edits/deletes without modifying the old knowledge engine. Draft-only edits do not change the active snapshot.
10. **Evidence guarantee**: server checks allowed candidate ID membership, current publication/role and the exact provided text. This does not prove semantic entailment; the report cannot advertise factual accuracy. No AI judge or hidden provider call in eval runs.
11. **Frontend**: current shell/nav.ts owns grouped links and QuickJump navigation; XGatewayApp.tsx owns routes. Reusing the old inline-nav patch would miss the live sidebar. Native createRoot/act is mandatory; Testing Library is not installed.
12. **016 boundary**: untracked specs/016-ai-support-widget-copilot-sla exists. Its expected widget-config/copilot/SLA implementation paths are absent in this checkout. Preserve it unchanged; concurrent016/018 work on the same checkout is prohibited because router/nav/widget hook points overlap.
