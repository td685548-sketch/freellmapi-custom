## Main DTOs

- SupportDeskWidgetConfig: {version:number,updatedAt:string,enabled:boolean,appearance:{primaryColor:string,title:string,welcomeMessage:string,position:'bottom-right'|'bottom-left',quickPrompts:string[]},intake:{required:boolean,fields:SupportDeskIntakeField[]}}. Defaults version1, enabled:false, required:false, fields:[], title Support Assistant, welcomeMessage empty, primaryColor #2563eb, bottom-right, prompts[]. Color exactly #RRGGBB, title<=80, welcomeMessage<=500, quickPrompts<=6 unique strings<=500; never raw HTML/CSS/URLs. required=true requires enabled=true and at least one required field.
- SupportDeskIntakeField: {key:string,label:string,type:'text'|'email'|'number'|'select',required:boolean,options?:string[]}. key lowercase [a-z][a-z0-9_]{0,39}; reject reserved/prototype/identity/security names after normalization: __proto__,prototype,constructor,role,user_role,user_id,userid,userrole,permissions,tenant_id,tenantid,token,contexttoken,request_id,conversation_id,intakereceiptid. options only select,1..20 unique nonempty strings<=80. Max10 unique fields.
- SupportDeskPublicWidgetConfig: {version,enabled,appearance,intake:{required,fields,schemaHash}}; no tenant signing secret, user token, policy budgets, customer values or operator data. schemaHash hashes normalized required flag + ordered fields; appearance-only edits do not invalidate accepted receipts.
- SupportDeskIntakeInput: {requestId:string,configVersion:number,values:Record<string,string|number>,conversationId?:string}. Unknown/missing fields rejected. Text trim/NFC<=500; email<=254 with syntactic validation; number finite bounded +/-1e9 (no implicit numeric string coercion); select exact membership. No customer-attribute binding or identity inference.
- SupportDeskStoredIntake (internal only): {receiptHash,tenantId,userId,role,requestId,schemaHash,conversationId:string|null,expiresAt,createdAt,values:validated values}. Never serialize this internal record through public routes.
- SupportDeskIntakeReceipt: {intakeReceiptId:string,expiresAt:string,schemaHash:string,replayed:boolean}. Opaque cryptographic receipt bound to tenant/userId/current role/schema and optional conversation. It never authenticates by itself. Raw receipt is encrypted in cached result; lookup uses sha256(receipt). Public responses never echo submitted values.
- SupportDeskConversationIntake: public projection {schemaHash,submittedAt,values?:masked values}. Persisted workflow metadata stores ONLY {schemaHash,submittedAt,receiptHash}; never duplicate raw/custom values into settings even when masking policy exempts a role. Canonical get/list hydrate a copy from the encrypted bound receipt and mask using original/current verified customer role; if role no longer matches receipt binding, omit values. No read-side writes or receipt hash in public projection. Trusted internalIntake is separate from public body.
- SupportDeskCopilotInput: {requestId:string,conversationId:string}. No role/messages/model/customerContext/policy/budget in body.
- SupportDeskCopilotResult: {jobId,requestId,conversationId,status:'completed'|'abstained',reason?:'no_evidence'|'invalid_result'|'sources_changed',summary:string,drafts:Array<{tone:'empathetic'|'direct'|'technical',text:string,citations:SupportEvidenceCitation[]}>,summaryCitations:SupportEvidenceCitation[],conversationSnapshot:string,evidenceSnapshot:string,policyVersion:number,modelUsed:string|null,usage:{promptTokens:number,completionTokens:number,totalTokens:number,accounting:'actual'|'estimated'},replayed:boolean,createdAt:string}. Completed has exactly3 distinct tones plus independently cited summary; abstained has fixed safe localized reason, summary empty/drafts[]/citations[]. - SupportDeskSlaPolicy: {version,updatedAt,enabled:boolean,targets:Record<SupportTicketPriority,{firstResponseMinutes:number,resolutionMinutes:number}>,routingRules:Array<{id:string,department:SupportDeskDepartment,keywords:string[]}>}. - SupportDeskTicketState: {tenantId,ticketId,conversationId?:string,version,cycle:number,cycleOpenedAt,tracking:'tracked'|'paused',policyVersion,policyTargets:copy of all4 priority targets,priority,department,routingSource:'rule'|'fallback'|'manual',firstHumanReplyAt:string|null,resolvedAt:string|null,terminal:boolean}. ## New migration

Agent1 creates only server/src/db/migrations/20261113_180001_support_service_desk.ts, registers once in defaults.ts and updates roundtrip expectation. Five tables:

1. x_support_desk_widget_configs: tenant_id PK/FK x_support_tenants cascade, version, encrypted payload/iv/tag, updated_at.
2. x_support_desk_intakes: receipt_hash PK, tenant_id FK cascade, user_id, role, request_id, fingerprint, schema_hash, conversation_id nullable, expires_at, encrypted payload/iv/tag, created_at; UNIQUE(tenant_id,user_id,role,request_id). payload contains raw validated values + replay receipt. No JWT/signing secrets stored. Bounded per-identity issuance <=10/hour, max100 live receipts per tenant/user; expired purge limited to that tenant, never inside read.
3. x_support_desk_copilot_jobs: id PK, tenant_id FK cascade, actor_id, request_id, fingerprint, conversation_id, state running/completed/abstained/failed, lease_until, dispatched_calls, reserved_tokens, spent_tokens, encrypted payload/iv/tag, created_at/updated_at; UNIQUE(tenant_id,actor_id,request_id). Hour/day windows use UTC fixed windows; usage and reservations live in these durable records. Retain enough usage rows until the daily window ends, even if cached result expires.
4. x_support_desk_sla_policies: tenant_id PK/FK cascade, version, encrypted payload/iv/tag, updated_at.
5. x_support_desk_ticket_state: composite PK(tenant_id,ticket_id), tenant_id FK cascade, version, cycle/opened_at, priority, department, policy_version, first_human_reply_at/resolved_at nullable, tracking, terminal, encrypted policy/routing metadata/iv/tag. No plaintext subject/reason/customer values/drafts.

Use existing encrypt/decrypt, migration up(db)/down(db), supported Db interface. Ensure base/lazy tenant schema, a second independent memory Db and populated up/down/up. Corrupt rows/missing table/read failures fail typed503; healthy missing policy returns a fresh default. No edits to older migrations or new ad-hoc schema in other owners' modules.
