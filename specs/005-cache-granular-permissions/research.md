# Research decisions
Existing broad route gates precede upstream routers; adapt these in the custom layer instead of editing dozens of handlers. Shared implication must be one-way (parent -> child only). Services/auth and services/users currently bypass all admin restrictions and need isolated grant-parsing changes. Existing key forms query roster for cosmetic suggestions; disable that query without view_keys so add-only is meaningful. Existing cache PUT toggles only enabled; add a standalone preferences route for enabled/persist with atomic writes. Persistence contains plaintext responses, so the UI explains scope and offers RAM-only.
